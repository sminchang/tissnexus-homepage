1440×900 화면에서 각 이미지가 **원본보다 얼마나 확대되어 보이는지** 측정해 우선순위를 나눴습니다 (2026-09-29 기준).

## 만들 때 공통 규칙

- **글자·로고·라벨을 넣지 마세요.** 시안처럼 칩에 "HUMIMIC" 같은 글씨가 들어가면 번역·수정이 불가능합니다. 글자는 모두 코드로 올립니다.
- **톤:** 흰색·연한 하늘색 배경, 유리 질감의 3D 렌더, 파랑·청록 계열 + 조직은 분홍·보라 포인트, 부드러운 보케. (시안과 같은 분위기)
- **배경형(1순위 대부분):** 화면 오른쪽 약 60%에 깔리고 **왼쪽 3분의 1과 아래쪽은 흰색으로 페이드**됩니다. 주제는 가운데~오른쪽에 두고, 왼쪽은 비워 두세요.
- **크기:** 표의 권장 크기는 레티나 화면(2배) 기준입니다. 이보다 크면 괜찮고, **비율**은 맞춰 주세요(가운데 기준으로 잘려 들어갑니다).
- **교체 방법:** 발표자료 작성자에게 슬라이드 번호 기준 요청서(`S24-2.png` 같은 요청 번호)를 전달했습니다. 받은 파일을 `docs/new-images/` 에 넣으면 `docs/이미지-요청-매핑.json` 으로 요청 번호 → 사이트 이미지 파일을 찾아 webp 변환·크기 조정 후 교체합니다.
